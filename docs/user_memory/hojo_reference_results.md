# Hojo MemoryEngine: Published Reference Results

These results were generated by the Hojo AI team using the configurations
documented for each run below. They are self-run evaluations listed as
**Published Reference Results**, not OmniMemEval reproduced results. The runs
used self-hosted Hojo MemoryEngine deployments and benchmark-specific
retrieval settings, so they should not be treated as directly comparable to
the reproduced OmniMemEval scores.

All runs were evaluated end to end, including memory ingestion, retrieval,
answer generation, and scoring, with the same answer and judge configuration:

| Component | Configuration |
| --- | --- |
| Answer model | `gpt-4.1-mini-2025-04-14` |
| Judge model | `gpt-4o-mini-2024-07-18` (LoCoMo, LongMemEval-S, BEAM, HaluMem) |
| PersonaMem v2 scoring | Rule-based option matching against the gold answer (no LLM judge) |
| Memory backend | Self-hosted Hojo MemoryEngine HTTP service |

## LoCoMo

The run covers all **1,986 LoCoMo questions** across 10 conversations. Each question went
through retrieval, answer generation, and LLM-as-a-judge scoring; adversarial
questions were judged against their `adversarial_answer`. All 1,986 answers
and judgments completed with no failures.

| Category | Questions | Correct | Judge accuracy |
| --- | ---: | ---: | ---: |
| Single-Hop | 841 | 782 | 92.98% |
| Multi-Hop | 282 | 231 | 81.91% |
| Temporal | 321 | 274 | 85.36% |
| Open-Domain | 96 | 70 | 72.92% |
| Adversarial | 446 | 393 | 88.12% |
| **Overall** | **1,986** | **1,750** | **88.12%** |

The four non-adversarial categories (1,540 questions, 1,357 correct) also
score 88.12% on their own, so the overall score is the same with or without
the adversarial questions. The Single-Hop, Multi-Hop, Temporal, Open-Domain,
and Overall values match the Hojo row in
[results.md](./results.md#published-reference-results).

Retrieval used semantic search with `top_k=20`, `candidate_limit=200`,
`min_score=0`, and `max_tokens=10000`. Strict-fair mode disabled action-query
expansion, multi-pass retrieval, and assistant-response query expansion.
Context-token statistics are not reported for this run. No dataset revision
hash or corrected answer key was recorded; no answer-key correction is
claimed.

covered reference fact, 0.5 for partial coverage, and 0.0 for incorrect or

statistics are not reported for this run. No answer-key correction is claimed.

## HaluMem-Medium

The run covers the full **3,467-question** medium split. The question-weighted
judge-based QA accuracy is **77.04%**. All 3,467 searches, answers, and
judgments succeeded, with no failed or skipped questions.

| Question type | Questions | QA accuracy |
| --- | ---: | ---: |
| Basic Fact Recall | 746 | 74.53% |
| Memory Boundary | 828 | 83.70% |
| Memory Conflict | 769 | 87.26% |
| Generalization and Application | 746 | 70.78% |
| Multi-hop Inference | 198 | 63.64% |
| Dynamic Update | 180 | 53.89% |

Retrieval used strict-fair semantic search with `top_k=20`,
`candidate_limit=200`, `min_score=0.5`, and `max_tokens=1500`. Ingestion stored
each message as its own `conversation_message` claim, indexed assistant
messages, and kept session time as provenance. Context-token statistics are
not reported for this run. No dataset revision hash or corrected answer key was
recorded; no answer-key correction is claimed.

## Deployment and reproduction

All runs called self-hosted Hojo MemoryEngine HTTP services. The evaluation
harness was a local OmniMemEval checkout with a Hojo adapter that implements
`add()`, `search()`, and `delete()`. Benchmark-specific retrieval settings are
listed in each section above.

These results are offered as published reference results. To be included in
the main **Reproduced Results** tables, the Hojo adapter, a credential-free
configuration example, setup instructions, and basic tests will be submitted
in a separate pull request. The results will then be reproduced through
OmniMemEval's shared benchmark pipeline using its baseline answer and judge
configuration.
